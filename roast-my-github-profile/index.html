About Roast My GitHub Profile

Roast My GitHub Profile is a free AI tool that analyzes your GitHub activity and delivers savage but honest feedback based on your real data—commits, repos, stars, and patterns. No signup needed.

How It Works

Enter your GitHub username and the tool fetches your public profile data via the GitHub API. Our AI then scores you on:

  • Repository Quality — Analyze README completeness, description quality, and maintenance status
  • Commit Hygiene — Judge your commit message clarity and frequency
  • Star Ratio — Compare repos to visibility and traction
  • Activity Pattern — Identify if you're a weekend warrior or ghost committer
  • Contribution Impact — Rate followers vs. public repos for real influence

Why You Should Use This

Your GitHub profile is your portfolio. Whether you're job hunting, building a personal brand, or just curious how you stack up, this tool gives you instant, shareable feedback. The roast is funny but factual—it's based on real metrics, not random insults.

Perfect For

  • Developers prepping for interviews
  • Open-source maintainers checking impact
  • Job seekers optimizing their GitHub brand
  • Tech professionals entertaining themselves

Share Your Roast

Generate a shareable card and post it to Twitter/X. Include your roast grade, your username, and the savage feedback. Developers love sharing their roasts—it's a badge of honor mixed with humor.

All data is fetched from GitHub's public API. No profile data is stored or sold. Your roast is generated in real-time based on public metrics.
