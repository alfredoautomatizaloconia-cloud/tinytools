How the roast works

    
This tool analyzes your actual tweet text — no API calls, no account access required. Everything happens in your browser. We score your tweets on 8 signals: hashtag density, emoji overload, self-promotion ratio, buzzword saturation, humblebragging, thread addiction, engagement-bait patterns, and average tweet length.

    
The roast is 100% deterministic — same tweets always produce the same grade. No AI costs, no randomness, no hallucinations. Just cold, hard pattern recognition pointing out what everyone already thought but was too polite to say.

    
What does your Twitter grade mean?

    
Grades range from S (rare gem — you actually add value to the timeline) down to F (chronically cringe, please seek help). Most people land somewhere in the C-B range, which means you're posting exactly like everyone else and nobody remembers you. Statistically, the most common personality type is "Thought Leader Cosplay."
