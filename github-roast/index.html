How it works

    
The tool fetches public GitHub data via GitHub's REST API (no signup, no token, no fetching anything private). We analyze: number of repos, stars earned, account age, languages used, most recent activity, README quality, follower-to-following ratio, repo-to-star ratio, and 20+ other signals.


    
The roast is generated from those real signals using a deterministic rule set — so the same username always produces the same roast (no AI hallucinations, no API costs, nothing leaves your browser except the GitHub API call). Results are based on data, not vibes.


    
Why this exists

    
Because LinkedIn celebrations are exhausting and we deserve a tool that points out when someone has 47 starred repos but contributed to none of them. Use it on yourself for humility, on your friends for chaos, on potential hires for fun.
